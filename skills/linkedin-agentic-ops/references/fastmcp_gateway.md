# Руководство по FastMCP Gateway: safe-linkedin-mcp

Микросервис [safe-linkedin-mcp](file:///c:/Users/Mikhail/OneDrive/nocode/CV_Azhy/safe-linkedin-mcp) обеспечивает безопасное взаимодействие с LinkedIn REST API v2 через протокол Model Context Protocol.

---

## 🛠️ Доступные Инструменты FastMCP

### 1. `get_linkedin_profile_status`
- **Назначение:** Проверяет валидность локального токена OAuth2 и статус аккаунта.
- **Возвращает:**
  - `authenticated`: bool
  - `person_urn`: URN пользователя (например, `urn:li:person:UwcyuZi1XS`)
  - `scopes`: список активных разрешений (`openid`, `profile`, `email`, `w_member_social`)
  - `expires_in_days`: оставшийся срок действия токена (максимум 60 дней)

### 2. `audit_linkedin_post`
- **Назначение:** Офлайн-валидация черновика на соответствие инвариантам без обращения к внешнему API.
- **Параметры:**
  - `text`: текст поста или комментария
  - `commentary_type`: тип публикации (`post`, `article`, `comment`)
- **Проверки:**
  - Отсутствие утечек ключей и секретов
  - Длина хука (до 150 символов)
  - Отсутствие запрещенных символов (включая символ em-dash \u2014)
  - Проверка отсутствия markdown-звездочек для комментариев

### 3. `publish_linkedin_post`
- **Назначение:** Публикация подтвержденного контента на личной странице или странице компании.
- **Параметры:**
  - `text`: проверенный текст публикации
  - `visibility`: видимость (`PUBLIC` или `CONNECTIONS`)
  - `target`: цель публикации (`personal` или `company`)
- **Поведение:**
  - Если пост не проходит валидацию инвариантов, сервер немедленно прерывает выполнение (fail-fast) и возвращает структурированную ошибку с кодом нарушения.

---

## 🔑 Управление Авторизацией и Токенами

1. **Файл токена:** `safe-linkedin-mcp/token.json`
2. **Срок жизни:** 60 дней.
3. **Обновление токена:**
   При истечении срока запустить скрипт авторизации:
   ```powershell
   cd safe-linkedin-mcp
   python core/auth.py
   ```
   Скрипт поднимет локальный сервер на `http://localhost:8000/callback`, откроет страницу авторизации LinkedIn и сохранит обновленный токен.

## 🧪 Запуск Тестов Сервера

Для проверки целостности всех инвариантов и инструментов:

```powershell
cd safe-linkedin-mcp
python -m unittest discover -s tests
```

Все тесты выполняются офлайн без расхода API-лимитов LinkedIn.
