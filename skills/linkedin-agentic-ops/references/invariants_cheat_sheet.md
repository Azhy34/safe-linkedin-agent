# Чек-лист Инвариантов Контента (Deterministic Shield)

Этот документ определяет жесткие правила валидации текстов для LinkedIn перед показом пользователю или отправкой в API.

---

## 🛑 5 Жестких Инвариантов

### 1. Запрет длинного тире (Zero Em-Dash Rule)
- **Правило:** Символ длинного тире (em-dash, код \u2014) строго запрещен во всех генерируемых текстах.
- **Почему:** Выдает шаблонный машинный стиль и нарушает персональные требования Михаила.
- **Чем заменять:**
  - Двоеточием `:`
  - Точкой `.`
  - Стандартным дефисом `-` (только для составных слов вроде e-commerce)
  - Новой строкой

### 2. Запрет Markdown-звездочек в комментариях (No Asterisks)
- **Правило:** Текст комментариев не должен содержать `**жирный**` или `*курсив*`.
- **Почему:** Поле ввода комментариев в веб-интерфейсе и мобильном приложении LinkedIn не поддерживает markdown и выводит звездочки как обычные символы, что выглядит неопрятно.

### 3. Правило первого экрана (150-Character Mobile Fold)
- **Правило:** Первые 140-150 символов (хук) обязаны быть завершенной мыслью, вызывающей желание нажать «see more».
- **Структура хука:**
  - Противоречие или сильное утверждение (например: «Connecting an AI model directly to the Google Ads API is a bad idea»).
  - Пустая строка после хука.

### 4. Нулевая утечка секретов (Zero-Leak Policy)
- **Правило:** Никаких `client_secret`, `access_token`, паролей или внутренних ID в тексте постов или логах.
- **В коде:** Все модели Pydantic используют маскирование или валидатор `validate_no_secrets`.

### 5. Принцип простоты Карпати (Simplicity & Punchy Tone)
- **Правило:** Избегать сложных теоретических терминов, если мысль можно передать простыми словами.
- **Ключевой нарратив:**
  - Напрямую к API модель не подключают.
  - Нужны рельсы и кастомные инструменты со своей бизнес-логикой.
  - Это убирает галлюцинации до того, как они коснутся рекламного кабинета.
  - AI работает как быстрый анализатор, а код держит безопасность.
  - Каждое действие логируется и трейсится.

## 🐍 Проверочный скрипт на Python

Перед отправкой через шлюз выполняется валидация:

```python
def validate_content_invariants(text: str, is_comment: bool = False) -> tuple[bool, list[str]]:
    errors = []
    
    # Проверка на длинное тире
    if "\u2014" in text:
        errors.append("Обнаружено запрещенное длинное тире (em-dash)")
        
    # Проверка на markdown звездочки для комментариев
    if is_comment and ("**" in text or "*" in text):
        errors.append("В комментарии обнаружены markdown-звездочки '**'")
        
    # Проверка мобильного фолда
    first_line = text.strip().split("\n")[0]
    if len(first_line) > 160:
        errors.append(f"Первая строка превышает 160 символов ({len(first_line)} симв.)")
        
    return len(errors) == 0, errors
```
